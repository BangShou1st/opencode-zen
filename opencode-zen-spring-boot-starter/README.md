# OpenCode Zen Spring Boot starter

Dependency aggregation entry point for Spring Boot applications. It brings in
the OpenCode Zen auto-configuration module and spring-boot-starter.

Add `com.github.BangShou1st.opencode-zen:opencode-zen-spring-boot-starter` to a
consumer; the current version is listed in the repository README. The artifact
is served by JitPack from the public GitHub tag — no credentials required.
